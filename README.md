# Från central kontroll till gemensam riktning

Detta är ett bokprojekt skapat för en svensk lärobok/handbok om enterprise arkitektur i en decentraliserad arkitekturorganisation.

## Innehåll
- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, projektstatus och exportmetadata.
- `chapters/` innehåller inledning och kapitelutkast.
- `assets/cover/cover.png` innehåller ett första genererat omslagsutkast.
- `assets/image-prompts/COVER.md` innehåller omslagsprompten.
- Inre illustrationer är avstängda enligt beslut.

## Nuvarande status
Projektet innehåller inledning och kapitel 1.
