# Övningar till kapitel 8: Beroenden mellan utvecklingsområden

## Övning 1: Hitta tre beroenden
Välj ett aktuellt initiativ och identifiera minst tre beroenden till andra utvecklingsområden.

För varje beroende:
- beskriv vad beroendet gäller
- klassificera det som informationsberoende, lösningsberoende eller beslutsberoende
- beskriv konsekvensen om beroendet inte hanteras
- ange ett konkret nästa steg

## Övning 2: Avgör hanteringsnivå
För varje beroende i övning 1, markera en av följande hanteringsnivåer:

| Hanteringsnivå | När passar den? |
|---|---|
| Direkt dialog mellan områden | När berörda parter har mandat och frågan är avgränsad |
| Stöd från central utvecklingsfunktion | När frågan behöver metodstöd, riktningsstöd eller sammanhang |
| Arkitekturforum | När frågan påverkar flera områden, principer eller gemensam riktning |
| Ledningsbeslut | När prioritering, finansiering eller mandat behöver avgöras på högre nivå |

## Övning 3: Förbättra ett beroendeflöde
Välj ett beroende som tidigare skapade försening, omarbete eller otydlighet.

Reflektera över:
1. När borde beroendet ha upptäckts?
2. Vilken information saknades?
3. Vem borde ha ägt nästa steg?
4. Vilket forum eller vilken dialog hade varit mest hjälpsam?
5. Vilken enkel rutin skulle minska risken att samma sak händer igen?
