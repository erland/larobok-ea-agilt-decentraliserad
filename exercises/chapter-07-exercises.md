# Övningar till kapitel 7: Behov, initiativ och arkitekturell påverkan

## Övning 1: Triagera tre initiativ

Välj tre aktuella eller nyligen genomförda initiativ.

För varje initiativ, fyll i:

| Fråga | Svar |
|---|---|
| Vilket behov ligger bakom initiativet? | |
| Vilken lösning eller vilket arbete föreslås? | |
| Vilka utvecklingsområden berörs? | |
| Vilken information, tjänst, process eller teknik påverkas? | |
| Vilken påverkningsnivå har initiativet: 1, 2, 3 eller 4? | |
| Vilken hantering är lämplig? | |

Avsluta med att jämföra initiativen. Vilket initiativ riskerar att bli för lokalt hanterat? Vilket riskerar att bli onödigt tungt hanterat?

## Övning 2: Från lösning till behov

Ta en lösningsformulerad beställning, till exempel “vi behöver införa system X” eller “vi behöver bygga integration Y”.

Skriv om den till:

1. bakomliggande behov
2. önskad effekt
3. berörda användare eller verksamhetsdelar
4. möjliga lösningsspår
5. arkitekturella frågor som behöver besvaras

## Övning 3: Skapa en triageringsrutin

Beskriv en enkel rutin för ditt utvecklingsområde.

Rutinens innehåll:

- När triagering sker
- Vem som deltar
- Vilka frågor som alltid ställs
- Hur beslutet dokumenteras
- När frågan lyfts till forum eller central funktion

## Reflektionsfråga

Vilken typ av initiativ i din organisation brukar upptäckas för sent som gemensam arkitekturfråga? Vad skulle behöva förändras för att se påverkan tidigare?
