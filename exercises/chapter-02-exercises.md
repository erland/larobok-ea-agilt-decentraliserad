# Övningar till kapitel 2: Från XLPM-logik till agil utvecklingslogik på organisationsnivå

## Syfte

Övningarna hjälper läsaren att se var äldre faslogik fortfarande påverkar arkitekturarbetet och hur organisationen kan röra sig mot mer kontinuerlig arkitektur.

## Övning 1: Identifiera kvarvarande faslogik

Välj ett aktuellt utvecklingsflöde.

Besvara:

1. Var krävs formell arkitekturgranskning?
2. Var uppstår väntan?
3. Vilka underlag tas fram innan arbetet startar?
4. Vilken arkitekturell kunskap uppstår först under genomförandet?
5. Vilka beslutspunkter skapar faktisk kvalitet?

Sammanfatta i tre kolumner:

| Behåll | Förändra | Ta bort eller ersätt |
|---|---|---|
| | | |
