# Exportguide

Export ska utgå från `docs/export-metadata.yaml`.

## Regler
- Inledningen ska ligga först: `chapters/00-inledning.md`.
- PDF ska ha innehållsförteckning före inledningen.
- EPUB ska ha luftig layout och inte ha innehållsförteckning som eget textkapitel.
- Markdown ska renderas till riktig formatering i EPUB/PDF/DOCX.
- Omslagsbild: `assets/cover/cover.png`.
- Inre illustrationer används inte i denna bok.
